Очистка ПДн сейчас

Прошедшие записи — в завершённые, закрытые старше срока хранения — удалить. Обычно идёт ночью в 03:30.

Перезапустить бот

Служба поднимет бот через 5 секунд. Задания сохранены в БД. При ручном запуске бот просто остановится.

Настройки из .env

Меняются на сервере в файле .env, затем бот перезапускается. Секреты не показываются.
