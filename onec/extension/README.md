# Расширение 1С «Бот_Интеграция» (сигналы в боты записи)

Задачи T063 и T064 этапа 0. Отправляет ботам сигналы `cancel-visit` и `finish-visit`
по контракту `docs/onec-contract.md` (раздел 2). Сначала применяется в **тестовой** копии УМЦ.

## Быстрая установка из готового файла

Собранное и проверенное на тестовой УМЦ расширение лежит в `onec/extension/Бот_Интеграция.cfe`
(только код и метаданные: значений констант и секретов в нём нет).

1. Конфигуратор → «Конфигурация» → «Расширения конфигурации» → «Добавить» → в новом расширении
   «Конфигурация» → «Загрузить конфигурацию из файла…» → `Бот_Интеграция.cfe`.
2. Снимите флажки «Безопасный режим» и «Защита от опасных действий», нажмите F7.
3. Перезапустите 1С:Предприятие и заполните константы (раздел 2) через
   «Функции для технического специалиста» → «Константы».

HTTP-сервис бота — отдельное расширение `TGBotAPI`, его актуальная (продовая) сборка —
`onec/TGBotAPI.cfe`, модуль — `onec/http-service.bsl`.

Разделы ниже описывают ручную сборку: нужны, если меняете код. После изменений сохраните расширение
в `Бот_Интеграция.cfe` и обновите соответствующие `.bsl` в этой папке.

## 1. Создать расширение

Конфигуратор → Конфигурация → Расширения конфигурации → Добавить:
имя `Бот_Интеграция`, префикс `Бот_`, назначение «Адаптация».

## 2. Константы расширения

| Имя | Тип | Значение на сервере |
|-----|-----|---------------------|
| `Бот_Включено` | Булево | Истина |
| `Бот_Адрес` | Строка(64) | `127.0.0.1` |
| `Бот_ПортTelegram` | Число(5,0) | `8001` |
| `Бот_ПортMAX` | Число(5,0) | `8002` |
| `Бот_СекретTelegram` | Строка(256) | `ONEC_WEBHOOK_SECRET` из `telegram_bot/.env` |
| `Бот_СекретMAX` | Строка(256) | `ONEC_WEBHOOK_SECRET` из `max_bot/.env` |

Права на константы-секреты дайте только роли администратора: модуль читает их в
привилегированном режиме, обычным пользователям доступ не нужен. Роли основной конфигурации
не видят новые объекты расширения, поэтому заимствуйте роль администратора (ту, что отмечена у
вашего пользователя: Администрирование → Пользователи → «Прочие», обычно «ПолныеПрава») через
«Добавить в расширение» и в её редакторе прав отметьте для шести констант `Бот_` права «Чтение»,
«Изменение», «Просмотр», «Редактирование». Без этого константы не видны в «Все функции → Константы».
Флажки расширения «Безопасный режим» и «Защита от опасных действий» снимите, иначе 1С запретит
расширять модули объектов и отправлять HTTP-запросы.

## 3. Общий модуль

Создать общий модуль `Бот_Сигналы` (флажки: **Сервер**; не глобальный, не вызов сервера) и вставить
текст из `ОбщийМодуль.Бот_Сигналы.bsl`.

## 4. Заимствованные документы

- Заимствовать `Документы → Заявка`, открыть модуль объекта расширения, вставить
  `Документ.Заявка.МодульОбъекта.bsl`.
- Заимствовать `Документы → Прием`, модуль объекта расширения —
  `Документ.Прием.МодульОбъекта.bsl`.
- Заимствовать и реквизиты, к которым обращается код: у «Заявки» — `Состояние`, `Ответственный`,
  `Примечание`, у «Приема» — `ДокументОснование`. В основной конфигурации раскройте документ →
  «Реквизиты» → правой кнопкой по реквизиту → «Добавить в расширение». Без этого проверка модуля
  выдаёт «Переменная не определена». Стандартные реквизиты (`Ссылка`, `ПометкаУдаления`)
  заимствовать не нужно.

## 5. Отключить старую отправку

Прежняя отправка отмены вписана прямо в основную конфигурацию: форма записи регистра сведений
«ПричиныОтменыЗаявок», процедуры `ПриЗаписиНаСервере` и `ОтправитьСигналБотуОбОтменеНаСервере`.
Она шлёт сигнал без секрета (новые боты отвечают 401), только при слове «бот» в причине и всё равно
пишет «✅ сигнал отправлен». Основную конфигурацию не правим, отключаем через расширение:

1. В основной конфигурации: «Регистры сведений» → «ПричиныОтменыЗаявок» → «Формы» → правой кнопкой
   по «ФормаЗаписи» → «Добавить в расширение».
2. В расширении откройте модуль этой формы и вставьте
   `РегистрСведений.ПричиныОтменыЗаявок.ФормаЗаписи.Модуль.bsl`.

Форма и ввод причины отмены работают как раньше, пропадает только старая отправка.

## 5а. Флажки онлайн-записи на формах (этап 1)

Флажок «Участвует в онлайн-записи» на карточках врача и услуги — пошагово в
`Справочник.Сотрудники.ФормаЭлементаУпр.md` и `Справочник.Номенклатура.ФормаЭлементаУпр.md`.
Флажок в расширении переживает обновления БИТ.

## 6. Проверка на тестовой базе

1. Записаться через тестового бота, найти заявку в журнале записи и отменить её любым способом.
   Бот должен прислать «Ваша запись была отменена нашими администраторами».
2. Записаться, создать из заявки «Приём» и провести его. Через 20 минут бот присылает просьбу
   об отзыве.
3. Ошибки отправки видны в журнале регистрации, событие «Бот.Сигналы». Если бот остановлен,
   сохранение документов в 1С не задерживается: отправка идёт фоновым заданием с таймаутом 5 с.

После проверки сохраните расширение в `onec/extension/Бот_Интеграция.cfe` и обновите `.bsl`:
код 1С хранится в репозитории (принцип II).
