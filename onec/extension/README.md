# Расширение 1С «Бот_Интеграция» (сигналы в боты записи)

Задачи T063 и T064 этапа 0. Отправляет ботам сигналы `cancel-visit` и `finish-visit`
по контракту `docs/onec-contract.md` (раздел 2). Сначала применяется в **тестовой** копии УМЦ.

## 1. Создать расширение

Конфигуратор → Конфигурация → Расширения конфигурации → Добавить:
имя `Бот_Интеграция`, префикс `Бот_`, назначение «Адаптация».

## 2. Константы расширения

| Имя | Тип | Значение на сервере |
|-----|-----|---------------------|
| `Бот_Включено` | Булево | Истина |
| `Бот_Адрес` | Строка(64) | `127.0.0.1` |
| `Бот_ПортTelegram` | Число(5,0) | `8001` |
| `Бот_ПортMAX` | Число(5,0) | `8002` |
| `Бот_СекретTelegram` | Строка(256) | `ONEC_WEBHOOK_SECRET` из `telegram_bot/.env` |
| `Бот_СекретMAX` | Строка(256) | `ONEC_WEBHOOK_SECRET` из `max_bot/.env` |

Права на константы-секреты дайте только роли администратора: модуль читает их в
привилегированном режиме, обычным пользователям доступ не нужен.

## 3. Общий модуль

Создать общий модуль `Бот_Сигналы` (флажки: **Сервер**; не глобальный, не вызов сервера) и вставить
текст из `ОбщийМодуль.Бот_Сигналы.bsl`.

## 4. Заимствованные документы

- Заимствовать `Документы → Заявка`, открыть модуль объекта расширения, вставить
  `Документ.Заявка.МодульОбъекта.bsl`.
- Заимствовать `Документы → Прием`, модуль объекта расширения —
  `Документ.Прием.МодульОбъекта.bsl`.

## 5. Удалить старую отправку

В основной конфигурации, в модуле формы записи регистра сведений «ПричиныОтменыЗаявок», удалите
вызов бота из `ПриЗаписиНаСервере` и процедуру `ОтправитьСигналБотуОбОтменеНаСервере`. Старый код
шлёт сигнал без секрета, и новые боты его отклонят. Кроме того, он срабатывал только при слове «бот»
в причине отмены.

## 6. Проверка на тестовой базе

1. Записаться через тестового бота, найти заявку в журнале записи и отменить её любым способом.
   Бот должен прислать «Ваша запись была отменена нашими администраторами».
2. Записаться, создать из заявки «Приём» и провести его. Через 20 минут бот присылает просьбу
   об отзыве.
3. Ошибки отправки видны в журнале регистрации, событие «Бот.Сигналы». Если бот остановлен,
   сохранение документов в 1С не задерживается: отправка идёт фоновым заданием с таймаутом 5 с.

После проверки выгрузите расширение (Конфигурация → Выгрузить конфигурацию в файлы) и замените
этими файлами содержимое `onec/extension/`: код 1С хранится в репозитории (принцип II).
