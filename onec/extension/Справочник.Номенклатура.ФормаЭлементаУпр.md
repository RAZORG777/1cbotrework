# Флажок «Участвует в онлайн-записи» на форме номенклатуры (этап 1, US4, T035)

Расширение `Бот_Интеграция`. Реквизит `УчаствуетВОнлайнЗаписи` уже есть в справочнике
«Номенклатура»; по нему `ServicesGET` решает, показывать ли услугу в боте (вместе с регистром
«Основные услуги сотрудников»).

1. Верхнее дерево «Конфигурация» → «Справочники» → «Номенклатура» → «Реквизиты» → правой кнопкой по
   `УчаствуетВОнлайнЗаписи` → «Добавить в расширение».
2. «Формы» → `ФормаЭлементаУпр` → «Добавить в расширение».
3. В заимствованной форме перетащите `Объект.УчаствуетВОнлайнЗаписи` в дерево элементов рядом
   с полем «Архив».
4. Свойства элемента: «Вид» — «Поле флажка», «Заголовок» — «Участвует в онлайн-записи»,
   «Подсказка» — «Услуга видна в ботах записи у врачей, которым она назначена в „Основных
   услугах сотрудников“».
5. F7, перезапуск. Проверка — quickstart.md › 6.
