# Флажок «Участвует в онлайн-записи» на форме номенклатуры (этап 1, US4, T035)

Расширение `Бот_Интеграция`. Реквизит `УчаствуетВОнлайнЗаписи` есть в справочнике «Номенклатура»;
по нему `ServicesGET` решает, показывать ли услугу в боте (вместе с «Основными услугами сотрудников»).

**Почему не поле с путём `Объект.УчаствуетВОнлайнЗаписи`**: в заимствованной форме платформа
не даёт выбрать этот путь (проверено 29.09 в тестовой УМЦ — выбор недоступен, ручной ввод не
принимается). Поэтому флажок — реквизит самой формы, а модуль расширения синхронизирует его
с объектом.

1. Заимствовать реквизит `УчаствуетВОнлайнЗаписи` и форму `ФормаЭлементаУпр` справочника
   «Номенклатура».
2. В заимствованной форме добавить реквизит формы `Бот_УчаствуетВОнлайнЗаписи` (Булево,
   заголовок «Участвует в онлайн-записи») и перетащить его в дерево элементов рядом с «Архив»,
   «Вид» — «Поле флажка».
3. Модуль формы — вставить `Справочник.Номенклатура.ФормаЭлементаУпр.Модуль.bsl`, Ctrl+F7.
4. У исходной формы нет обработчика «ПередЗаписьюНаСервере»: выделить корневой элемент «Форма»
   в дереве элементов → свойства (Alt+Enter) → «События» → «ПередЗаписьюНаСервере» → выбрать
   `Бот_ПередЗаписьюНаСервере`.
5. F7, перезапуск. Проверка — quickstart.md › 6.

**Важно**: у элемента `Бот_УчаствуетВОнлайнЗаписи` назначить событию «ПриИзменении» процедуру
`Бот_УчаствуетВОнлайнЗаписиПриИзменении` (она в модуле): без неё изменение флажка не делает
карточку изменённой, и «Записать и закрыть» закрывает её без записи (проверено 29.09;
свойство реквизита «Сохраняемые данные» в заимствованной форме не устанавливается).
