# Флажок «Участвует в онлайн-записи» на форме сотрудника (этап 1, US4, T034)

Расширение `Бот_Интеграция`, основная конфигурация не меняется. Реквизит `УчаствуетВОнлайнЗаписи`
уже есть в справочнике «Сотрудники»; по нему HTTP-сервис бота (`DoctorsGET`) решает, показывать ли
врача в боте.

1. Конфигуратор → верхнее дерево «Конфигурация» → «Справочники» → «Сотрудники» → «Реквизиты» →
   правой кнопкой по `УчаствуетВОнлайнЗаписи` → «Добавить в расширение» → `Бот_Интеграция`.
2. Там же «Формы» → правой кнопкой по `ФормаЭлементаУпр` → «Добавить в расширение».
3. В дереве «Бот интеграция» откройте заимствованную `ФормаЭлементаУпр` (двойной щелчок).
4. В правом верхнем окне «Реквизиты» раскройте `Объект` и перетащите `УчаствуетВОнлайнЗаписи`
   в дерево элементов формы (левое верхнее окно) рядом с полем «Участвует в расписании».
5. Выделите новый элемент → свойства (Alt+Enter):
   - «Вид» — «Поле флажка»;
   - «Заголовок» — «Участвует в онлайн-записи»;
   - «Подсказка» — «Врач виден в ботах записи (Telegram, MAX), если у него есть график».
6. F7, перезапуск 1С:Предприятие. Проверка — quickstart.md › 6.

Права: реквизит основной конфигурации, права на него дают роли основной конфигурации
(у администраторов — «Полные права»), отдельной настройки не нужно.
