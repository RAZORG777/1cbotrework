# Contract: статистика

## События (daily_stats.name)

| name | Когда | Сводка |
|------|-------|--------|
| `booked` | /book успешно | Новых записей |
| `rescheduled` | /reschedule успешно | Переносов |
| `cancelled_patient` | отмена в форме или кнопкой напоминания | Отменили пациенты |
| `cancelled_clinic` | сигнал 1С cancel-visit, если отменял не пациент | Отменила клиника |
| `confirmed` | «Подтвердить визит» (впервые) | Подтвердили визит |
| `visited` | сигнал 1С finish-visit | Пришли на приём |
| `new_users` | новый пользователь бота | Новых пользователей |

## Шаги воронки (`funnel:<step>`, уникальные пользователи за день)

| step | Кто отмечает | Название |
|------|--------------|----------|
| `open` | форма: экран «Филиал» в режиме записи | Открыли форму |
| `branch` | форма: экран «Врач или услуга» | Выбрали филиал |
| `doctor` | форма: экран «Дата и время» | Выбрали врача и услугу |
| `time` | форма: экран «Пациент» | Выбрали время |
| `submit` | сервер: запрос /book | Отправили данные |
| `booked` | сервер: /book успешно | Записались |

## API формы

`POST /track` (MAX — `/max/track`), `Authorization: tma <initData>`, тело `{"step": "open"}`.
Ответ `{"status": "ok"}`; неизвестный шаг — 422.

## API админки (база `/admin/api`, MAX — `/max/admin/api`)

| Метод | Путь | Ответ |
|-------|------|-------|
| GET | `/stats?days=7` (1–400) | `{"days": [{"day": "2026-10-09", "booked": 3, …}], "totals": {…}, "funnel": [{"step": "open", "title": "Открыли форму", "count": 12}], "events": [{"name": "booked", "title": "Новых записей"}], "report_time": "20:00", "tomorrow": 6}` |
| POST | `/stats/report` (X-Admin-Request) | `{"status": "ok", "sent": 2}`; без ADMIN_IDS — 409 `NO_ADMINS` |
