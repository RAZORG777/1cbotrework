# Implementation Plan: Новые тексты уведомлений ботов

**Branch**: `005-bot-messages` | **Date**: 2026-10-08 | **Spec**: [spec.md](spec.md)

## Summary

В каждом боте появляется модуль `app/texts.py` (одинаковый по содержанию в обоих ботах): филиалы
с адресом, телефоном и маршрутом, даты по-русски и функции текстов из
[contracts/messages.md](contracts/messages.md). Кнопки собираются платформенно: Telegram —
`app/keyboards.py` (`style`, `url`, `web_app`, `callback_data`), MAX — `app/keyboards.py`
(`intent`, `link`, `open_app`, `callback`). Места отправки (запись, перенос, отмена, напоминания,
кнопки напоминаний, сигналы 1С, приветствие) переходят на эти функции.

## Technical Context

Python 3.13, FastAPI, без новых зависимостей. Тесты — pytest: тексты по контракту, отсутствие
смайликов во всех сообщениях, кнопки с цветами.
